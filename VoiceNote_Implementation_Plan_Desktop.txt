IMPLEMENTATION PLAN: VOICENOTE DESKTOP (.EXE)

1. PROJECT OVERVIEW
VoiceNote is a Windows desktop application that converts voice recordings into searchable knowledge.
The application is built entirely in Python and packaged as a standalone .exe.

Architecture

PySide6 Desktop UI
    |
Application Controller
    |
-------------------------------------
| Audio Recording
| Whisper Speech-to-Text
| AI (Llama/Gemma via Ollama)
| Task Extraction
| Semantic Search
-------------------------------------
    |
SQLite + ChromaDB

2. TECHNOLOGY STACK
UI: PySide6 (Qt)
Language: Python
Database: SQLite
Vector DB: ChromaDB
Speech-to-Text: faster-whisper
LLM: Llama/Gemma (Ollama)
Audio: sounddevice, PyAudioWPatch
Packaging: PyInstaller
Installer: Inno Setup
Version Control: Git/GitHub

3. IMPLEMENTATION ROADMAP
Phase 1: Project setup, UI, SQLite
Phase 2: Audio recording, note management
Phase 3: Whisper, AI summary, tasks, semantic search
Phase 4: Export, analytics, testing
Phase 5: Package EXE using PyInstaller and create installer

4. VERIFICATION
Test recording, transcription, summaries, search, exports, installer and standalone execution.
